# US Sailing references

Original downloads from [Forms, Diagrams, Equipment](https://www.ussailing.org/competition/rules-officiating/race-officers/materials-for-race-officers/forms-diagrams-equipment/), retrieved 2026-10-31.

[manifest.csv](manifest.csv) records each direct source URL, byte count, SHA-256 checksum, and download status. All 20 downloads passed file-signature checks. `Fleet_Race_Rotations.doc` is RTF served with a `.doc` extension; its original name and bytes are preserved.

Coverage includes the race-management forms and spreadsheets linked on that page, excluding its hearing-request form. Both Word/PDF or Excel/PDF versions are retained where offered. The page also lists diagrams, equipment lists, and flag archives; these are outside this form-reference collection and were not downloaded.

These are references, not the working forms. Preserve their original contents and notices. The source page includes older materials; publication there does not verify current rules wording.
