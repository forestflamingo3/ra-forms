Race administration forms

Use Race-Administration-Event-Package.dotx through Word File > New to create an event copy, or open the supplied blank .docx packet directly.
Enter the Event name on the first page once. It is mapped to the Event identification across the packet, including the reference sheets. Save the event copy as .docx.
The packet contains 18 forms and references on 45 pages, including its one-page contents sheet. Print the page ranges needed for the race committee and mark boats.

The four previously completed custom forms retain their editable content controls and protected layouts. The newly converted paper forms use native Word tables and writing spaces, with mapped Event controls.
All Word files are macro-free. The source folder was not modified.

RCWindLog.docx preserves the two side-by-side blocks, 30 writing rows, and 25-column underlying grid. Wind Direction headings span their original groups. The wind log prints on one Letter page.
The scoring matrix retains its landscape grid and diagonal divisions as native Word table borders.
The round-robin schedules embedded as images in the source PDF remain images, preserving their exact entries and grids; the surrounding text is editable in the Avenir style. Other rotation graphics retain their print geometry.
Avenir is the requested typeface. As in the accepted prototypes, the font table specifies Calibri as its fallback.
No formulas were found in the populated cells of the 10 Excel workbooks. Heading tables contain the original supplied values, including both 180-degree boundary rows and 360-degree rows.
